# おひめさま きせかえ

▶ **あそぶ:** https://sakusaku117.github.io/princess-dressup/

3〜4歳から遊べる、おひめさまの着せ替えゲームです。かんむりやドレス、アクセサリーを選んで、自分だけのおひめさまを作ります。

`index.html` をブラウザで開くだけで遊べます。インストールや通信は不要です。

## 遊び方

- 上の絵のボタンで種類を選び、下の絵を選ぶとおひめさまに付きます。
- 付けているものをもう一度選ぶか「なし」を選ぶと外れます。
- 🎲 おまかせ / 🧹 さいしょから / 📖 アルバム / ✨ できた! は右下のボタンです。
- 失敗や時間制限はありません。付けたものの名前は音声で読み上げます。

## キーボード操作

| キー | うごき |
|---|---|
| `←` `↑` `↓` `→` | 黄色い枠(カーソル)を動かす |
| `Enter` / `スペース` | きめる |
| `Esc` / `Backspace` | もどる |
| `1`〜`9`, `0` | 種類を直接えらぶ |
| `M` | 音のオン・オフ |

マウスやタッチでも遊べます。

## えらべるもの

かんむり・かみがた・かみのいろ・ドレス・かみかざり・ネックレス・イヤリング・ステッキ・はね・ばしょ の10種類です。

## アルバム

「✨ できた!」を押すと、作ったおひめさまがアルバムに残ります(最大100人)。あとから見返したり、その姿から着せ替えを再開したりできます。

今の姿とアルバムは、ブラウザの localStorage に保存されます。別の端末やブラウザとは共有されません。
